# Purdue FORGE (FPGA Organization for Research, Growth, and Education)
We are the premier organization to promote the understanding and use of FPGAs to further students’ knowledge of Hardware Description Language (HDL) and the usefulness and practicality of the FPGA in a standard semiconductor design process. An FPGA is a physical prototyping tool that allows engineers to implement and test an integrated circuit design without the costly and time-consuming silicon fabrication process. We utilize existing FPGAs for various sizes of projects as well as design new development boards both for the use of our club and for the benefit of Purdue ECE.
